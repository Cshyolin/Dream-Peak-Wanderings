# 欢迎来到《云山异变 - 峰林行止》！

这是焦作THP03《峰林行止》中剧情视觉小说的源代码。这次活动预计将在2026年十一期间与大家见面。

这份视觉小说目前还未完成，预计将在2026年十月之前完成，在THP当天分段放映。

## 关于对话音频

本工程使用RenPy的自动音频功能。在使用MoeGoe生成音频（wav格式）后，用voice_generator.py转为ogg格式，保存在指定目录下。RenPy对wav格式的支持仅限于特定规格的wav，与直接生成的不同，因此需要转换。
